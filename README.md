# AetherTerm

**Milla Rayne's Sovereign Terminal & Companion**

This is an *individual program repository* in the Milla-Rayne / Rayne OS empire.

Part of our sovereign, offline, modular world — streamlined for focused planning, coding, integrating, testing, and debugging.

Individual repos like this (DEAR-MILLA, Elara3.0, SARIi2.0, the Milla Rayne core, AetherTerm) let us move faster while staying connected through clean APIs, bridges, and shared memory.

## Run Locally

**Prerequisites:** Node.js, local Ollama (primary brain for Milla responses), optional Gemini key for gemini-chat panel features.

1. Install dependencies:
   `npm install`
2. (Optional) Configure keys in .env.local as needed. Primary Milla intelligence routes through local empire bridges (see aether_bridge and core_os).
3. Run the app:
   `npm run dev`

It boots with video, offers VFS file/chat creation, real-time collab, sandbox, and deep integration with the full empire (including milla_chat TUI core).

See the AetherTerm server.ts for the bridge to Milla's core.
